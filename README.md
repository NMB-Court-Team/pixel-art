# [像素画工作台](https://nmb-court-team.github.io/pixel-art/)

一个零依赖的 48×48 响应式像素画编辑器，支持桌面浏览器与触屏设备。

## 主要功能

- 画笔和橡皮分别保存圆形/方形笔尖及 `0～8 px` 半径，默认均为方形单像素；画笔支持 `Shift + 点击` 从上一笔终点连续画直线
- 填充工具提供「邻接填充」和「选区填充」；选区填充在没有选区时会填满整个画布
- 图形工具（顶部「图形」）提供矩形、空心矩形、圆形、空心圆形和直线五种二级图形，按住 `Shift` 可临时切换空心 / 实心，绘制结果同样沿用当前颜色与对称设置
- 水平、垂直、双向、四向和八向对称
- 矩形、手涂、魔棒与同色选择四种选区模式：魔棒单击选中与点击格颜色相同且相连的整片区域（含相连透明区域）；同色选择一键全选整幅同色格子（透明背景同样可全选）；支持复制、剪切、移动和粘贴，矩形选区可拖到画布外并自动裁切，存在选区时局部绘图和填充不会改动选区外像素
- 默认隐藏、可随时切换的像素网格；支持 20%～800% 视角缩放、滚轮按 10% 步进、鼠标右键平移和双指手势；工具栏最左侧的「鼠标」工具（移动视图）选中后，按住左键 / 单指拖动只平移画布、不绘制任何内容（无二级面板，触屏双指仍是缩放 + 移动）
- 背景色**绑定在调色板颜色上**：在调色板选中一个颜色后点「设置为背景色」（该色已是背景色时按钮变为「清除背景色」）。它不占颜色名额、不作画布像素，在画布上只是底层填充色；「网格」左侧的「背景」按钮（默认开启）切换显示背景色还是透明棋盘格。**它的计格数 = 画该色的格子 + 所有透明格**（导出时这些格子都会是它），所以「最少色块」与调色板计数都按这个口径（但「整理」/导出合并只用真正画在画布上的格子来挑合并目标，既不会把别的颜色并进背景色，也不会把背景色合并掉）；删除该颜色会同时清除背景色，并自动选中所有透明格。取色点到透明格会取到该颜色；**只有导出时**才会用它填充透明像素
- 独立透明像素和可调上限（默认 16、可设 1–16）的动态调色板，支持感知顺序自动排序、拖动重排、更新、添加、删除和清空色板
- 空调色板的默认候选颜色为 `#808080`，首次绘制时按需自动加入调色板
- 响应式颜色工作室：宽屏为右侧栏，窄屏或竖屏为可滚动底栏
- Lab 色域、HSL 色相环、RGB/HSL/Lab 通道三种选色视图；色图和明度滑块支持实时候选预览与限制边界重绘
- 基于 CIEDE2000 的可调颜色距离限制，默认 `ΔE00 = 12`、内置下限为 `8`，主界面与图片导入界面保持同步
- 最少色块规则：同一颜色在画布上占据的格子数不能少于设定值（默认 `32` 格、内置下限 `16`、可设 `16–2304`，不能关闭；调色板中尚未使用的 `0` 格颜色不算违规）。合并规则见下方「关键操作」
- 图片导入先定位并实时预览量化结果，可选无偏差 / 颜色偏移恢复 / 邻接对比增强 / 区域感知均衡四种导入算法，并按算法提供对应参数
- 项目数据、PNG 导入导出和本地自动保存（默认导出 1× PNG，按住 `Alt` 导出 16×；导出前会弹窗填写文件名，留空则为 `未命名.png`。PNG 不写 `tRNS` 透明槽位、位深按用色数取 1/2/4 位，体积较小且仍是标准 PNG）
- 从文本导入：粘贴「导出文本」生成的纯文本（`base64(deflate(48 字节调色板 + 1 字节背景色槽位 + 每格 4 位索引))`）即可完整还原画面与调色板（背景色槽位的格子会还原成透明像素并把该颜色记为背景色）；同时兼容旧插件生成的 `floor_patterns` 配置（`name`/`colors`/`pattern`）。两种格式按内容自动识别，带实时预览
- 工具、对称模式、颜色规则和画布状态可自动恢复；所有有效修改进入统一的撤销/重做历史
- 单文件离线版 ΔE00 颜色分辨测试工具，可调整 2×2～6×6 候选布局，保证候选颜色互不重复，并按本轮候选色差范围连续评分

## 关键操作

- 色图拖动只改变候选颜色，不会自动修改调色板或历史记录
- 在色图上 `Shift + 点击` 添加新颜色，`Alt + 点击` 更新当前选中颜色；也可以使用侧栏按钮确认
- 在画布上按住 `Alt` 临时取色（与导出时的 `Alt` 无关），可从其他像素切换当前颜色
- 更新调色板颜色会立即刷新所有引用该颜色 ID 的像素；此类全局颜色操作不受选区限制
- 候选颜色尚未加入调色板时直接绘制会自动添加；调色板已满或候选色不符合距离规则时，会提示并回退到当前选中颜色
- 删除单个颜色或清空色板前会要求确认，相关画布像素会变为透明，并可通过撤销恢复
- 导出前会先检查最少色块规则：存在格子数不足的颜色时，列出这些颜色与各自格数（超过 4 个时只列前 4 个并报总数）——取消则整个导出作罢、画面不变；确认则先把它们自动并入相邻或最接近的颜色（一条可撤销历史）再进入文件名弹窗。图片导入、文本导入和像素量化会自动合并；手动编辑只在调色板里标红提示，可随时点「整理」合并
- 导出 PNG 会先弹出文件名弹窗：输入框默认留空、占位显示「未命名」，只需填基础名（自动补 `.png`）；名字会自动去掉路径分隔符等文件系统非法字符、结尾点号/空格与 Windows 保留设备名，并限制在 80 字符内；留空或只剩非法字符时按 `未命名.png` 导出，`Enter` 直接导出、`Esc` 或「取消」放弃；弹窗里会显示输出尺寸、倍数与当前用色数
- 「导出 PNG」`Alt + 点击` 导出 16×。文件面板里「导出 PNG」右侧的「跳转提交」按钮会在新标签页打开作品提交地址；该地址目前是占位链接（`js/app.js` 顶部的 `SUBMIT_URL`，标有 TODO），替换成实际地址即可
- 「导出文本」与 PNG 导出共用同一套导出前检查，随后弹出带文本框的纯文本弹窗，内容为 `base64(deflate(1201 字节))`：前 48 字节 = 16 个调色板颜色 × RGB888（按调色板顺序、未用槽位补 0），第 49 字节 = 背景色槽位（0–15，或 255 表示无背景色），其后 1152 字节 = 每格 4 位颜色索引（2 格 1 字节、高位在前）；弹窗打开时自动复制到剪贴板，「复制」按钮可再次复制
- 画布左上角（与「网格」「缩放」同一行）的「教程」按钮打开可翻页的使用教程（`←` `→` 或上一页 / 下一页翻页，右上角 × 或 `Esc` 退出）；标题行右侧的「编辑」按钮在新标签页打开 GitHub 上的 `tutorial.md` 编辑页。首次打开网页会自动弹出一次，之后是否再自动弹出由 `localStorage` 的 `pixelAtelier:tutorial:v1` 标记决定
- 新增或导入颜色达到颜色数量上限（主界面与图片导入同步可调）时会阻止操作并提示；把上限调到低于当前颜色数会被阻止并标红，回退到当前颜色数；低于最小 ΔE00 下限的输入会标红并回退
- 调色板右上角的「整理」按钮会把所有不足最少格数的颜色并入相邻颜色（优先并到邻接边界最长的一色，四周无邻居时并到 `ΔE00` 最近的一色），整条操作只产生一条可撤销历史；被合并掉的颜色会从调色板移除，因此也会释放颜色名额
- 最少色块低于内置下限 `16` 的输入会标红并回退，与最小 ΔE00 的处理方式一致；两个规则输入都位于调色板颜色列表下方
- 可见像素总数不足最少格数时规则无法满足，此时「整理」会把画面统一为格子最多的那一色，并在提示里说明

## 教程内容（tutorial.md）

教程内容来自根目录 `tutorial.md`：以 `##` 二级标题划分页面，运行时自动读取并转换成可翻页弹窗，支持 `-` 列表、`**加粗**`、`` `代码` `` 与 `[链接](url)`；读取失败（例如 `file://` 直接打开）时回退到页面内置的教程内容。

## 浏览器兼容性

建议使用当前仍受支持的 Chrome、Edge、Firefox 或 Safari。项目依赖原生对话框、Pointer Events、ResizeObserver 和 Canvas；较旧的浏览器或内嵌 WebView 不在兼容范围内。通过 `file://` 直接打开时，项目数据复制会在 Clipboard API 不可用时自动回退到传统复制方式。

## 批量转换（script/imgs2pixel.py）

把 `script/input/` 里的图片（PNG/JPEG/WebP/BMP/GIF/TIFF）批量转成 `48×48` 的 1× 像素画，输出到 `script/output/pixel_art/`。规则与编辑器一致且全部可调：

- 画布 `48×48`、颜色数量上限 `16`（内置范围 `1–16`）、两色最小色差 `ΔE00 ≥ 12`（内置下限 `8`）、同一颜色至少占 `16` 格（内置下限 `16`、上限 `2304`）、`alpha < 32` 记为透明；
- 非 1:1 的图片默认取**中心最大正方形裁切**后缩放填满画布（`--fit crop`，不留透明边）；需要保留整图时用 `--fit contain`（等比缩放居中、四周透明），另有 `cover`、`stretch`；
- 流程与网站的图片导入相同：裁切/缩放 → 感知量化（颜色超上限时）→ 色差不足按最小代价合并 → 过小色块并入相邻/最接近的颜色 → 输出索引色 PNG 并回读校验；
- 控制台逐张打印触发的规则与修改动作（`⚠` 违反规则并已修改、`·` 仅信息），并写出 `changes.log`（第一节：哪些图片不合颜色规则、被怎么改；第二节：哪些非 1:1 图片被中心裁切；第三节：**结果含透明像素的图片清单**，逐张给出透明格数与占比）与 `errors.log`（失败原因）。

脚本的 `--alpha-threshold`（默认 32）只用于读图时判定透明。`pngs2indexed.py` 是通用写入器，它的同名参数默认是 128，两者独立，改其中一个不会影响另一个。

```bash
py script/imgs2pixel.py                                   # 处理 script/input/
py script/imgs2pixel.py 图片目录 -r                        # 递归子目录
py script/imgs2pixel.py --max-colors 8 --min-delta-e 16 --min-color-pixels 32
py script/imgs2pixel.py --fit contain --resample lanczos --scale 16 --dry-run
```

依赖 `Pillow` 与 `numpy`（`py -m pip install Pillow numpy`）；`--dry-run` 只做规则检查与日志、不输出图片。

## 快捷键

- `B` 画笔、`E` 橡皮、`F` 填充、`M` 选区、`G` 网格，按住 `Alt` 在画布上临时取色（导出时的 `Alt` 是 16× 倍数）
- 使用画笔完成一笔后，`Shift + 点击` 可从上一笔终点连接到新位置
- `Ctrl/Cmd + Z` 撤销，`Ctrl/Cmd + Y` 重做
- `Ctrl/Cmd + C/X/V` 复制、剪切、粘贴选区
- `Delete` 删除选区内像素并保留选区
- `Enter` 放置，`Esc` 取消选区或移动

## 数据模型

像素保存稳定的颜色 ID，而不是直接保存 HEX。调色板重排只改变导出索引，不改变画面；编辑颜色会同步影响引用该 ID 的所有像素。透明使用 `null` 独立表示，不占用颜色名额。最少色块格数与最小 ΔE00、颜色数量上限一样保存在自动存档和项目数据里，缺失时回退默认值 `32`。
