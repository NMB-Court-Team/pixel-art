# [像素画工作台](https://nmb-court-team.github.io/pixel-art/)

48×48 像素画编辑器，用于制作色盲派对小游戏的地板图案。无需安装依赖，支持电脑和触屏。

## 绘图与选区

- 画笔、橡皮各自保存设置：圆形或方形笔尖，半径 0～8 px，默认单像素。
- 画笔画完一笔后，Shift + 点击从上一笔终点连直线。
- 邻接填充作用于相连同色区域；选区填充填满选区，无选区时填满画布。
- 图形支持矩形、圆形及其空心样式，还有直线。画矩形或圆形时，Shift 切换实心与空心。
- 对称支持水平、垂直、双向、四向旋转、八向旋转；再点当前模式关闭。
- 选区支持矩形、手涂、魔棒、同色选择。魔棒选上下左右相连的同色区域，同色选择选全部同色像素；也能选透明像素。
- 选区可复制、剪切、移动、粘贴。有选区时，绘图、擦除和填充只影响选区内；更新调色板颜色仍影响全图。

## 视图

网格默认隐藏。视图缩放范围 20%～800%，滚轮每次调整 10 个百分点。右键拖动平移，触屏用双指缩放和平移；选「平移」工具后可用左键或单指拖动。

颜色面板在宽屏右侧、窄屏或竖屏底部，支持 Lab 色域、HSL 色相环和 RGB/HSL/Lab 输入。

## 调色板与颜色规则

| 设置 | 默认值 | 可设范围 |
| --- | --- | --- |
| 颜色上限 | 16 色 | 1～16 色，不能低于现有调色板颜色数 |
| 最小色差 | ΔE00 = 12 | 不低于 8 |
| 每色最少格数 | 32 格 | 16～2304 格 |

格数按同色像素总数计算，无须相连；未使用的颜色不计。

拖动色图选色；Shift + 单击添加，Alt + 单击更新选中颜色，也可点按钮。更新影响全部同色像素。调色板支持自动排序和拖动排序。

空调色板默认选色 #808080。绘制时自动添加新颜色；超出上限或色差不足时，提示并改用最接近的已有颜色。

格数不足的颜色标红，点「整理」合并；文本导入会自动合并，图片导入默认使用「颜色偏移恢复＋格数择优」，比较补足格子与合并颜色的损失；勾选「忽略」跳过格数整理。添加、更新颜色会检查色差；图片导入会调整色差，文本导入只提示色差不足。

合并优先选邻接最多的达标颜色（含斜向），无邻接目标则选色差最小的颜色。没有颜色达标时，保留格数最多的颜色。背景色不会被合并掉，但已绘制格数达标时可接收其他颜色。合并可撤销。

删除颜色、清空调色板均需确认，相关像素变透明。删除单色后，选中全部透明像素。

## 背景色

选中调色板颜色，点「设置为背景色」。不额外占颜色名额，编辑时保留透明像素，导出时填为背景色。

背景色格数 = 已绘制的同色像素 + 全部透明像素。计数和不足提示按此计算，合并目标只看已绘制格数。

「背景」切换背景色和透明棋盘格，不影响导出。透明处取色会取到背景色；删除对应颜色会清除背景色。

## 导入、导出与保存

### 图片

「导入图片」可调整位置、缩放和预览。默认推荐「颜色偏移恢复＋格数择优」，在处理方法列表中排在首位，联合比较补足格子与合并颜色的损失。

还可选择「感知量化＋格数补足」：

- 用加权代表色迭代优化平方 ΔE00 误差，代表色来自原图，并检查最终 RGB 颜色的最小色差。大色簇使用候选子集，属于近似优化。
- 小面积颜色优先从附近、改色损失较低的格子补足。固定调色板与空间代价后，用最小费用流分配格子，同时保证每种保留颜色达到最少格数。空间代价为到原始同色区域的四邻域距离平方，透明区域阻断距离搜索。
- 可见格子总数不足以容纳所有颜色时，逐次合并增加感知误差最少的颜色，再重新分配；调色板子集选择为启发式。
- 不填充透明格；可见格子少于一色的最低格数时，保留一色，并在预览与导入提示中说明无法达标。
- 预览显示补足颜色数、改色格数和合并颜色数。大幅提高最少格数会扩大细节区域，可在预览中比较效果。邻近补色是偏好，不保证每色连通。

「区域感知均衡」使用相同的原图代表色与格数补足，在此基础上平滑弱边缘、保护强边缘：

- 以所有可见格子的透明度加权平方 ΔE00 为保真项，不再按区域平均色整片替换，也不进行颜色偏移恢复。
- 四邻域的原图色差决定边缘代价：相近颜色之间轻度抑制碎块；强边缘只补偿对比损失，保护目标取原图色差与「边缘保护上限」的较小值，不强迫相邻区域异色。
- 先得到满足配额的分配，再用最小费用流提出联合调整、逐格局部下降。所有接受的调整都降低同一总误差并保持最低格数；这是有限迭代的局部优化，不保证空间目标的全局最优。
- 「区域处理强度」为 0 时等同「感知量化＋格数补足」；提高「相近颜色阈值」会扩大平滑范围。配额过高仍会扩大细节，颜色上限和最小色差也可能限制可保留的细节。

还可选择颜色偏移恢复、基础量化、增强对比度；这三种方法在启用格数整理时沿用合并规则。「忽略」默认关闭，勾选后所有方法均跳过格数补足与合并，区域感知均衡仍保留边缘处理；每次重新选图恢复默认方法并关闭「忽略」。

默认推荐的「颜色偏移恢复＋格数择优」是保留原版的独立选项，完全沿用颜色偏移恢复的配色与最大偏移设置，只更换格数整理：

- 对初始格数不足的颜色，联合比较保留并补足、合并到保留配色的多种组合；初始已达标颜色保留。容量足够时也可以合并，不一律扩张。
- 所有组合使用同一代价：透明度加权平方 ΔE00，加上到原始同色格子的四邻域距离平方（系数为最小色差的四分之一的平方）。透明区域阻断距离搜索，不能到达时使用画布总格数作为距离；不填充透明格。
- 每个可行组合用最小费用流重新分配所有可见格子，保留颜色达到最低格数；增长和合并的连锁影响在最终分配中一起计算。先评估一条合并链，再用色差下界剪枝，最多搜索 96 个状态，选择评估过的最低代价方案；达到搜索上限时预览显示「限量搜索」，不保证所有组合的全局最优。仅能容纳一色时直接比较所有允许的单色方案。
- 预览显示比较方案数、补足颜色数、改色格数和合并颜色数。勾选「忽略」时与原版颜色偏移恢复完全一致；全部颜色原本已达标时不改动。可见格子不足一色最低格数时仍提示无法达标。

算法参考：[代表色聚类](https://scikit-learn-extra.readthedocs.io/en/latest/modules/cluster.html)、[带容量约束的最小费用流分配](https://developers.google.com/optimization/flow/assignment_min_cost_flow)。

「导出 PNG」默认 48×48，Alt + 点击导出 768×768。文件名最长 80 字符，自动补 .png、处理非法字符和 Windows 保留名；留空为「未命名.png」。

默认导出无透明槽位的索引色 PNG，位深为 1、2 或 4 位。压缩不受支持或编码失败时改用 Canvas 导出。

「提交作品」在新标签页打开作品提交问卷（腾讯问卷），地址在 js/app.js 顶部的 SUBMIT_URL。

### 文本与项目数据

「导出文本」生成并尝试复制文本，也可手动点「复制」。「从文本导入」支持该文本和旧插件的 floor_patterns 配置（name、colors、pattern），自动识别并预览。

文本将透明像素存为背景色，导入后不再透明；未使用的普通颜色不会恢复。导入还会合并格数不足的颜色，不能用作完整备份。

备份请用「复制项目数据」并自行保存，可保留透明像素、完整调色板和设置。「导入项目数据」用于恢复，颜色数不能超过当前上限。

### 导出前检查

PNG 和文本导出前：

1. 有透明像素但无背景色，须设置背景色或补画完整；弹窗里可直接点「选中所有透明像素」把它们全部选出来。
2. 有颜色格数不足，提示合并。取消不修改，确认立即合并，可撤销。
3. PNG 随后弹出文件名输入框；此时取消导出，不会撤销合并。

像素总数或背景色格数不足时，合并后仍可能不达标。

画面和部分工具设置自动保存在当前浏览器中，清理浏览器数据可能丢失。重要作品请另存项目数据。撤销、重做仅用于当前编辑过程。

## 教程与文件结构

首次打开自动显示教程，也可点「教程」打开。左右方向键或按钮翻页，Esc 关闭；「编辑」打开 GitHub 编辑页。

tutorial.md 按二级标题分页，支持列表、加粗、行内代码和链接。加载失败时使用 index.html 内置教程。首次显示标记保存在 localStorage 的 pixelAtelier:tutorial:v1 中。

| 文件 | 用途 |
| --- | --- |
| index.html | 编辑器界面与内置教程 |
| css/global.css | 样式与响应式布局 |
| js/app.js | 编辑器状态、绘图、颜色及文件操作 |
| js/png-indexed.js | 索引色 PNG 编码器 |
| js/import-optimizer.js | 图片导入的最少格数分配与小面积颜色补足 |
| tutorial.md | 使用教程 |
| color-test-standalone.html | 可离线打开的颜色分辨练习工具 |
| 混凝土调色板.gpl | GIMP 调色板文件 |

颜色分辨工具支持 2×2～6×6 布局，按当轮色差计分。平均测试色差仅供练习参考，不代表视觉分辨极限。

## 算法验证

运行 `node --test tests/*.test.js`。测试将配额分配与小规模穷举解对比，并覆盖相邻补色、多色竞争、透明格、容量不足和完整 48×48 / 16 色图案。

## 浏览器与数据格式

项目使用原生对话框、Pointer Events、ResizeObserver 和 Canvas。文本导入导出还需要 DecompressionStream 和 CompressionStream。通过本地文件方式打开时，教程加载可能失败，此时使用内置教程；复制操作会在 Clipboard API 不可用时尝试兼容方式。

像素保存稳定的颜色 ID，透明像素使用 null。调色板重排不改变画面，更新颜色会影响所有引用该 ID 的像素。

导出文本为 base64(deflate(1201 字节))：前 48 字节存储 16 个 RGB888 调色板槽位，未使用槽位补 0；第 49 字节存储背景色槽位（0～15，255 表示未设置）；其后 1152 字节存储像素索引，每格 4 位，每字节两格，高位在前。
